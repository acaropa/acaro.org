# Politica de seguridad

## Reportar vulnerabilidades

Reporta vulnerabilidades de forma privada al equipo mantenedor de ACARO. No abras issues publicos con detalles explotables.

Incluye, cuando sea posible:

- Ruta o funcionalidad afectada.
- Pasos de reproduccion.
- Impacto esperado.
- Evidencia no destructiva.
- Version, commit o fecha aproximada observada.

## Alcance

Este repositorio contiene el frontend Next, backend Express, migraciones MySQL y configuracion de CI del sitio `acaro.org`.

Quedan fuera de alcance pruebas destructivas, exfiltracion de datos, fuerza bruta, denegacion de servicio y acceso a cuentas sin autorizacion explicita.
